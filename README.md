# Zeran Wang — Academic Homepage

This website uses the same AcadHomepage Jekyll structure as the supplied reference site. It is configured in English with Zeran Wang's profile, CV-derived content, photo, and GitHub link.

## Publish with GitHub Pages

1. Create the public repository `I2eady.github.io` on GitHub.
2. Upload the entire contents of this folder to its `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/(root)`.
4. The site will be available at `https://i2eady.github.io/` after GitHub Pages finishes building it.
